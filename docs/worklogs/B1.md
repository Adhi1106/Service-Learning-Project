### 2026-11-15: Build record

**Who did this:** the whole app, including this area, was written in a single
session using Claude Code (an AI coding assistant), directed by the project
owner. No team member wrote this code by hand. The member who owns this area
is responsible for reading it, running it and being able to explain it, and
records that work in their own entries above.

**What was built in this area**

- Login with salted scrypt password hashes and 12-hour session cookies (`lib/auth.ts`, `lib/password.ts`)
- Role checks: `requireRole` on every page, `apiUser` on every API route
- Thirteen API endpoints under `app/api/` (listed in CONTRACTS.md, C3)
- Input validation with Zod on everything that is saved (`lib/api.ts`)
- All read queries for pages and routes (`lib/queries.ts`)
- Attendance save as one transaction with upsert, followed by the rules

**How it was checked**

- Browser run: no login → 401 from the API and a redirect to the login page; warden → 403 on alerts, cases, stock table, case update and reset; warden opening a manager page is sent home; wrong password is rejected; negative quantity, future date and absence without a reason each return 400; a case cannot move backwards (409).
- Not done: https, deployment, password change, account management.
